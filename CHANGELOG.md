# Changelog

## 0.1.0 - 2026-11-17

First public snapshot, with a fresh history.

- Drawing primitives, u8g2 text, images, animations, dithering.
- RGB and grayscale colour, optional alpha channel.
- Effects: 19 scene transitions, plasma/perlin/static painters, solo animations.
- Scene manager with a message ring, FPS pacing, timeouts, overlay and transitions.
- QR code and wrapped text block widgets.
- LED-strip indication subsystem (`ind/`).
- Host test suite with ASan/UBSan and golden frame hashes.
- Browser lab: the library as wasm with a timeline and a pixel loupe.
- MIT license; third-party notices for u8g2, fonts and optional dependencies.
